소프트웨어 첫걸음: 파이썬으로 회전판과 스피커 움직이기

실험 중에는 노트북 한 대가 회전판을 돌리고, 소리를 내고, 녹음하고, 계산까지 해요. 이 페이지는 그중 지금 가진 부품으로 바로 할 수 있는 두 가지, 회전판 조작과 스피커 소리 내기부터 다뤄요. 아두이노가 없어도 시뮬레이터로 따라 할 수 있어요.

1

노트북이 하는 일

그림 1 · 연결과 대화 방법 (파란 선이 이번에 다루는 부분)

회전판은 글자로 대화해요. 노트북이 g-30(−30°로 가라)을 한 줄 보내면, 아두이노가 모터를 돌리고 다 끝나면 ok를 돌려보내요. 문제가 있으면 err ...로 이유를 알려 줘요. 아두이노 IDE의 시리얼 모니터에 손으로 치던 것을 파이썬이 대신 보내는 거예요.

스피커는 노트북 이어폰 단자의 왼쪽·오른쪽 채널로 구분해요. 왼쪽 채널에만 소리를 넣으면 스피커 A에서만 소리가 나요. 실험 2에서 A·B에 서로 다른 소리를 동시에 낼 수 있는 이유예요.

시리얼 명령파이썬하는 일
?t.status()각도, 스위치, 드라이버 켜짐, 원점 여부
e1 / e0t.enable(True/False)모터 드라이버 켜기·끄기 (끄면 힘이 빠짐)
ht.home()리밋 스위치로 원점을 찾고 0°로 감
g-30t.goto(-30)원점 기준 절대 각도로 이동 (−65 ~ +65)
m10t.nudge(10)원점 없이 조금 움직이기 (±30° 이내, 배선 시험용)
ot.bench_origin()벤치 원점: 리밋 스위치 없이 지금 위치를 0°로 믿음 (조립 전 책상 위 시험용)
zt.set_zero()지금 위치를 0°로 정함 (카메라 십자선에 맞춘 뒤)
2

설치

코드는 프로젝트 폴더의 작업파일/파이썬에 있어요. 파이썬 3.9 이상을 깔고, 그 폴더에서 아래를 한 번 실행해요. 가상환경(.venv)은 이 프로젝트용 패키지를 따로 담는 상자예요.

# PowerShell에서, 작업파일\파이썬 폴더로 이동한 뒤
> py -m venv .venv
> .venv\Scripts\activate
> pip install -r requirements.txt
# 아두이노가 안 보이면 CH340 드라이버를 설치해요 (호환 보드)
# 터미널에서, 작업파일/파이썬 폴더로 이동한 뒤
$ python3 -m venv .venv
$ source .venv/bin/activate
$ pip install -r requirements.txt
# 포트 이름은 /dev/cu.usbmodem… 또는 /dev/cu.wchusbserial… 처럼 보여요

다음에 다시 쓸 때는 activate 줄만 다시 실행하면 돼요. 아두이노 IDE의 시리얼 모니터가 열려 있으면 파이썬이 포트를 열 수 없으니 꼭 닫아요.

3

따라 하기

step0

장치 확인

패키지가 다 깔렸는지, 아두이노와 오디오 장치가 보이는지 확인해요. UMA-16이 오면 "16채널 입력" 표시가 붙어요.

$ python step0_check_devices.py
  [있음] numpy  [있음] pyserial  [있음] sounddevice  [있음] soundfile
시리얼 포트
  COM5          USB-SERIAL CH340 (COM5)  ← 아두이노 후보 (CH340 (호환 보드))
오디오 장치
    3  입력  0 / 출력  2  스피커/헤드폰   [기본 출력 ← 스피커는 여기로 나가요]
step1

회전판 돌리기

먼저 시뮬레이터(--port sim)로 연습해요. 가짜 아두이노가 진짜와 같은 답을 같은 시간만큼 걸려서 보내요. 진짜 아두이노로 할 때는 --port를 빼요(4장).

$ python step1_turntable.py --port sim
[연결] sim: turntable ready. ? 로 상태 확인
명령> g10
<< err 먼저 h로 원점을 찾으세요
명령> h
   ok
명령> g-30
   ok
명령> ?
<< angle_deg=-30.038 steps=-267 limit=떨어짐 driver=켜짐 homed=yes
명령> q

−30°를 보냈는데 −30.038°가 나오는 건 모터가 한 바퀴를 3200칸으로 나눠 움직이기 때문이에요. 한 칸이 0.1125°라서 가장 가까운 칸(−267칸)으로 가요. 매번 원점 기준 칸 수로 계산하니 오차가 쌓이지 않아요. --demo를 붙이면 원점 → −30° → 0° → +30° → 0°를 자동으로 해요.

step2

스피커 A·B 소리 내기

앰프 볼륨을 최소로 두고 시작해요. 아무 옵션 없이 실행하면 채널 확인 소리가 나와요. 스피커 A에서 낮은 소리, 쉼, 스피커 B에서 높은 소리 순서여야 해요.

$ python step2_play_sound.py
00_채널확인.wav  4.5초, 48000 Hz, 스테레오(파일에 적힌 대로 A·B)
  기대: 스피커 A에서 낮은 소리(1 kHz) → 쉼 → 스피커 B에서 높은 소리(2 kHz)
$ python step2_play_sound.py --tone 4000 --side B --seconds 2
step3

돌리고 → 기다리고 → 소리 내기

나중에 할 자동 데이터 수집과 같은 순서예요. 각도마다 0.5초 기다려 흔들림을 멈춘 뒤 소리를 내고, 결과를 기록/ 폴더에 csv로 남겨요. UMA-16이 오면 "소리 내기"가 "소리 내면서 16채널 녹음"으로 바뀌어요.

$ python step3_rotate_and_play.py --port sim --angles -60 0 45

4

실제 하드웨어로 하기

시뮬레이터에서 돌던 코드는 그대로 진짜 아두이노에서도 돌아요. --port sim만 빼면 돼요. 처음 켤 때는 아래 순서를 지켜요.

HW1

스케치 올리기

아두이노 IDE 2에서 작업파일/아두이노/turntable/turntable.ino를 열고, 도구 → 보드는 Arduino Uno, 포트는 아두이노 포트를 골라 업로드해요. 11/4 판에 벤치 원점 명령 o가 추가됐으니 전에 올렸어도 다시 올려요. 끝나면 시리얼 모니터를 닫아요. 열려 있으면 파이썬이 포트를 못 열어요.

Windows에서 포트가 안 보이면 호환 보드용 CH340 드라이버를 설치해요. Mac은 대부분 바로 보여요.

HW2

배선과 전류 맞추기

문서/배선_작업순서.md 1~2단계(통전 검사, A4988 Vref 약 0.9 A)를 먼저 끝내요. 12V를 켠 채로 모터 선을 꽂거나 빼면 드라이버가 바로 망가져요. 모터 축에는 테이프로 작은 깃발을 붙여 도는 방향을 볼 수 있게 해요.

HW3

점검 스크립트

hw_check.py가 하나씩 움직이고, 눈으로 본 결과를 y/n으로 물어요. 문제가 있으면 무엇을 고칠지 알려 주고, 결과를 기록/에 남겨요.

$ python hw_check.py

  → 실패: 떨기만 함: 12V 끄고 한 코일 쌍의 두 선을 바꿔 꽂기 (배선 2단계)

점검 순서: 연결 → 드라이버 켜기 → 방향(10°) → 원점과 −60°·+60°·0° 왕복 → 리밋 스위치(10초 동안 눌러 보기) → 스피커 A·B 채널.

HW4

그다음은 step1~3을 진짜로

지금 상태원점실행
조립 전: 모터만 책상 위, 리밋 스위치 없음벤치 원점 opython step1_turntable.py --demo --bench
조립 후: 리밋 스위치가 −70°에 달림원점 찾기 hpython step1_turntable.py --demo
스피커까지 연결위와 같음python step3_rotate_and_play.py --bench --angles -30 0 30

벤치 원점은 켤 때마다 지금 위치를 0°로 믿는 거라, 위치가 매번 달라져요. 실험에서는 조립 후 h로 잡은 원점만 써요.

5

연습 과제

모두 --port sim으로 할 수 있어요. 코드는 turntable.py의 Turntable을 불러 쓰면 돼요.

과제 1 · 처음

실험 1 각도표

−60°부터 +60°까지 5° 간격으로 돌리는 명령을 만들어요. 각도는 몇 개이고, step3로 한 바퀴 도는 데 몇 초 걸리나요?

과제 2 · 처음

오류 일부러 내기

g10을 원점 없이, g80, m40을 보내 보고 어떤 err가 오는지 적어요. 파이썬에서는 TurntableError로 잡혀요.

과제 3 · 중간

무작위 각도

실험 3처럼 ±60° 안의 무작위 실수 각도 20개로 돌고, 10번마다 t.home()을 다시 하는 스크립트를 만들어요(random.uniform).

과제 4 · 중간

A와 B 동시에

audio.py로 A에는 1 kHz, B에는 2 kHz를 동시에 내 봐요. 힌트: 모노 두 개를 numpy.column_stack으로 스테레오로 만들어요.
