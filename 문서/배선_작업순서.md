# 배선 작업 순서

회전판 제어부(아두이노·모터·리밋 스위치)와 음원부(앰프·스피커)의 배선 순서와 확인 방법이다. 위에서부터 순서대로 하고, 각 단계의 확인을 통과한 뒤 다음 단계로 넘어간다.

## 절대 하지 말 것

1. 12V가 켜진 상태에서 모터 선을 꽂거나 빼지 않는다. A4988이 바로 망가진다.
2. A4988을 거꾸로 꽂지 않는다. 드라이버의 EN 핀을 쉴드의 EN 표시에 맞춘다.
3. PAM8403에 5V 넘는 전원을 넣지 않는다. 12V 어댑터와 헷갈리지 않게 선에 표시한다.
4. 스피커 A·B의 (−)선을 하나로 묶거나 GND에 연결하지 않는다. PAM8403은 BTL 출력이라 L−, R−가 접지가 아니다.
5. 납땜 직후 뜨거운 부분을 만지지 않고, 인두기는 반드시 거치대에 둔다.

## 전체 연결표

| 출발 | 도착 | 비고 |
|---|---|---|
| 12V 2A 어댑터 → DC잭 젠더 | CNC 쉴드 전원 단자 (+, −) | 극성은 멀티미터로 확인 |
| NEMA17 4선 | 쉴드 X축 모터 단자 (2B 2A 1A 1B) | 코일 쌍을 멀티미터로 찾음 |
| 리밋 스위치 COM | 쉴드 X− 단자의 GND 핀 | |
| 리밋 스위치 NO | 쉴드 X− 단자의 신호 핀 (D9) | 눌리면 LOW |
| (선택) 두 번째 리밋 스위치 | X+ 단자 (같은 D9) | +쪽 비상 정지 |
| 아두이노 USB | USB-C 허브 | |
| UMA-16 USB, 카메라 USB | USB-C 허브 (UMA-16은 3m 연장선) | |
| USB 전원 케이블 (자른 쪽) | PAM8403 +5V, GND | 극성 확인 후 납땜 |
| 3.5mm 케이블 (자른 쪽) | PAM8403 입력 L, GND, R | Tip=L, Ring=R, Sleeve=GND |
| PAM8403 L+, L− | 스피커 A (+, −) | 2심 선 한 가닥 쌍 |
| PAM8403 R+, R− | 스피커 B (+, −) | 2심 선 다른 쌍 |

쉴드 핀 (CNC 쉴드 V3, X축): STEP = D2, DIR = D5, EN = D8 (LOW일 때 켜짐), X−·X+ 리밋 = D9.

## 1단계. 전원 없이 하는 통전 검사 (멀티미터)

1. **모터 코일 쌍:** 모터 선 4가닥 중 두 가닥씩 저항을 잰다. 약 1.5Ω이 나오는 두 쌍이 각각 코일이다. 끊긴 것처럼 나오면 다른 코일이다. 17HS4401의 흔한 색 배치는 검정·초록이 한 쌍, 빨강·파랑이 한 쌍이지만, 색은 믿지 말고 잰 값으로 정한다.
2. **3.5mm 케이블:** 한쪽 플러그를 자른 뒤, 남은 플러그의 끝(Tip), 가운데 고리(Ring), 몸통(Sleeve)과 각 선 사이의 통전을 확인한다. 선에 L, R, G를 적은 테이프를 붙인다.
3. **DC잭 젠더:** 어댑터를 꽂고 콘센트에 연결한 뒤 젠더의 두 나사 단자 사이 전압을 잰다. +12V가 나오는 쪽을 쉴드의 + 단자로 연결한다. 확인한 뒤 어댑터를 뽑는다.
4. **USB 전원 케이블:** DC 플러그를 자르고, 두 선 끝이 서로 닿지 않게 벌려 놓은 상태에서 USB를 꽂아 전압을 잰다. +5V인 선에 표시하고 USB를 뽑는다.

## 2단계. 모터 제어부

1. 아두이노 위에 CNC 쉴드를 꽂는다.
2. X축 드라이버 자리 아래에 점퍼 캡 3개(MS1, MS2, MS3)를 모두 꽂는다. 1/16 마이크로스텝이 된다.
3. A4988을 X축 자리에 꽂는다. EN 핀 위치를 쉴드 표시와 맞춘다. 방열판이 있으면 칩 위에 붙인다.
4. **모터는 아직 연결하지 않는다.** 12V를 쉴드 전원 단자에 연결하고, 아두이노는 USB로 노트북에 연결한다.
5. **전류(Vref) 조정:** 멀티미터 (−)를 쉴드 GND에, (+)를 A4988의 가변저항 위 금속에 대고 드라이버로 천천히 돌린다. 목표 전류는 약 0.9A이다(모터 정격 1.7A, 방열판 없는 A4988의 안전 범위). 드라이버 위 저항 표시(R100, R050, R200)를 보고 아래 값에 맞춘다.

| 저항 표시 | Rs | 목표 Vref (0.9A) |
|---|---|---|
| R100 | 0.1Ω | 약 0.72V |
| R050 | 0.05Ω | 약 0.36V |
| R200 | 0.2Ω | 약 1.44V |

   식: 전류 = Vref ÷ (8 × Rs)

6. 12V를 뽑고, 모터 선을 연결한다. 한 코일 쌍은 1A·1B에, 다른 쌍은 2A·2B에 꽂는다.
7. `작업파일/아두이노/turntable/turntable.ino`를 업로드하고 시리얼 모니터를 연다(115200, 새 줄).
8. 12V를 다시 연결하고 `?` → `e1` → `m10` → `m-10`을 차례로 보낸다.
   - 모터가 떨기만 하고 돌지 않으면 12V를 끄고 한 코일 쌍의 두 선을 바꿔 꽂는다.
   - 회전판을 위에서 볼 때 + 방향이 반시계가 아니면 스케치의 `DIR_INVERT`를 바꾼다(방향 약속은 팀에서 정해 구상도에 적는다).
   - 모터가 손으로 만져서 뜨거우면(60°C 이상) Vref를 조금 낮춘다.

## 3단계. 리밋 스위치

1. OMRON SS-5의 COM과 NO 단자에 선을 납땜하고 열수축 튜브로 절연한다. NC는 쓰지 않는다.
2. COM 선은 X− 단자의 GND 핀, NO 선은 신호 핀에 꽂는다. 어느 핀이 GND인지는 멀티미터로 쉴드 GND와 통전되는 핀을 찾아 확인한다.
3. 시리얼 모니터에서 `w`를 보내고 스위치를 눌러 "눌림/떨어짐"이 바뀌는지 본다.
4. 설치 위치는 측정 범위 밖인 약 −70°이다. 회전판 아랫면 가장자리에 박은 나사 머리가 레버를 누르게 한다. 두 번째 스위치를 쓰면 약 +70°에 두고 X+ 단자에 같은 방법으로 연결한다.
5. 조립 후 `h`로 원점 찾기를 해 본다. 200° 안에서 스위치를 못 찾으면 스스로 멈춘다.

## 4단계. 음원부 (앰프·스피커)

1. USB 전원 케이블의 +5V 선을 PAM8403의 +5V(VCC) 단자에, 다른 선을 GND 단자에 납땜한다.
2. 3.5mm 케이블의 L, R, G 선을 PAM8403 입력 L, R, GND에 납땜한다.
3. 스피커 선 10m를 반으로 잘라 두 쌍을 만든다. 한 쌍은 L+·L− → 스피커 A, 다른 쌍은 R+·R− → 스피커 B에 연결한다. 두 스피커 모두 + 단자에 같은 색 선이 가게 한다.
4. 앰프 볼륨을 최소로 하고, USB 전원을 허브에 꽂고, 3.5mm를 노트북에 꽂는다.
5. 노트북의 소리 향상·공간 음향 기능을 끈다(Windows: 사운드 설정 → 출력 장치 속성 → 오디오 향상 끄기).
6. `작업파일/신호/signals/00_채널확인.wav`를 재생한다. **스피커 A에서 낮은 소리(1 kHz), 쉼, 스피커 B에서 높은 소리(2 kHz)** 순서로 나와야 한다. 반대로 나오면 앰프 출력이나 입력의 L·R을 바꾼다.
7. 볼륨은 1.5m 거리에서 또렷이 들리는 정도로 하고, 소리가 찌그러지면 낮춘다.

## 5단계. 전체 연결 후 확인

- [ ] 노트북 장치 관리자에서 UMA-16(오디오 입력 16채널), 카메라, 아두이노(COM 포트)가 모두 보인다.
- [ ] `h` → `g-60` → `g60` → `g0`이 문제없이 끝난다.
- [ ] USB 선이 ±60° 회전에서 당기거나 걸리지 않는다(여유 약 30cm, 책상에 테이프로 고정).
- [ ] **드라이버 소음 확인:** 모터를 `g0`에 두고 아무 소리도 내지 않은 채 10초씩 두 번 녹음한다(`e1` 상태 1번, `e0` 상태 1번). 두 녹음을 비교해 `e1`일 때 고음 잡음이 보이면 녹음할 때 드라이버를 끈다.
- [ ] **드라이버를 끌 때 각도가 밀리는지 확인:** `g5` → `e0` → `e1`을 여러 번 반복하며 카메라 십자선의 위치가 변하는지 본다. 드라이버를 끄면 모터가 가장 가까운 정지 위치(1.8° 간격)로 끌려갈 수 있다. 밀린다면 녹음 중에도 드라이버를 켜 두거나, 측정 각도를 1.8°의 배수로 정한다.

## 문제 해결

| 증상 | 원인과 해결 |
|---|---|
| 모터가 떨기만 함 | 코일 쌍이 섞임 → 12V 끄고 한 쌍의 선 순서를 바꿈 |
| 모터가 전혀 안 움직임 | 12V 미연결, 드라이버 방향, Vref가 0에 가까움, `e1` 안 함 |
| 스텝을 잃음(각도가 점점 틀어짐) | Vref가 너무 낮음, 속도가 빠름 → 스케치의 `PERIOD_FAST`를 키움 |
| 드라이버가 뜨거움 | Vref를 낮추고 방열판을 붙임 |
| 리밋 스위치가 항상 "눌림" | NO 대신 NC에 연결했거나 신호·GND 핀이 바뀜 |
| 스피커에서 "웅" 소리 | 노트북 충전기를 빼고 배터리로 해 봄(접지 루프) |
| 한쪽 스피커만 나옴 | 3.5mm 선 L·R·G 확인, 노트북 모노 오디오 설정 확인 |
