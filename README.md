# 뉴턴 음향카메라

물리 동아리(민족사관고) 활동. UMA-16 v2 마이크 배열과 카메라로 음향카메라를 만들고, 소리 방향 추정의 정확도를 빔포밍과 딥러닝으로 비교한다. 기간 8주, 인원 4~6명.

## 방향 계산 실행과 결과

프로젝트 폴더의 터미널에서 다음을 실행하면 녹음 분석과 결과 저장을 한 번에 수행한다.
다른 컴퓨터의 최초 설치 방법과 실제 마이크 녹음 입력법은 [빔포밍 안내](작업파일/빔포밍/README.md)에 있다.

```sh
.venv/bin/python 작업파일/빔포밍/main.py --demo
```

바로 볼 수 있는 결과: [단일 음원 그림](작업파일/빔포밍/예시결과/단일음원/direction.png) · [요약 표](작업파일/빔포밍/예시결과/단일음원/summary.csv) · [두 음원 그림](작업파일/빔포밍/예시결과/두음원/direction.png).
이 예시는 **가상 16채널 녹음**으로 생성했으며 실제 장비의 측정 결과가 아니다. CSV는 엑셀·Numbers에서 열 수 있다.

## 작업파일

- `작업파일/빔포밍/` — 현재 방향 계산의 개발 위치. 계획서의 지연-합 빔포밍으로 녹음의 방향별 세기·최대 방향·소리 지도를 계산한다. 목적·입출력·실행법은 폴더의 `README.md`. 가상 녹음과 실제 WAV 파일 입력 지원, 실물 정확도는 미검증.
- `작업파일/방향추정/locate_sound.py` — 이전 단계의 도착 시간차 연습 코드. 추가 설치 없이 `python3 작업파일/방향추정/locate_sound.py --demo`로 실행한다. 계획서의 지연-합 빔포밍 개발은 위 폴더에서 이어 간다.
- `작업파일/실험계획서/content.py` — 계획서 본문. 고친 뒤 `python build2.py`(pdf) → `node make.js`(docx)
- `작업파일/아두이노/turntable/turntable.ino` — 회전판 제어·배선 테스트 (명령: `?`, `w`, `e1/e0`, `m`, `h`, `g`, `z`)
- `작업파일/신호/make_signals.py` — 실험용 소리 파일 생성. 만들어 둔 파일은 `signals/` (채널 확인용 `00_채널확인.wav` 포함)
- `작업파일/요구서/` — 요구서 작업본 xlsx
