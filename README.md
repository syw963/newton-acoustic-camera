# 뉴턴 음향카메라

물리 동아리(민족사관고) 활동. UMA-16 v2 마이크 배열과 카메라로 음향카메라를 만들고, 소리 방향 추정의 정확도를 빔포밍과 딥러닝으로 비교한다. 기간 8주, 인원 4~6명.

## 폴더 구성

| 경로 | 내용 |
|---|---|
| `진행상황.md` | 날짜별 진행 기록, 현재 상태, 다음 할 일 |
| `설계_및_결정사항.md` | 확정된 장치 설계, 요구서 작성 규칙, 확인이 필요한 것 |
| `CLAUDE.md` | Claude와 작업할 때의 지침 |
| `요구서/` | 학교 제출용 물품 구입 요구서 (xls) |
| `문서/` | 실험 계획서, 배선 작업 순서, 프로젝트 소개 문서, 장치 구상도 |
| `문서/보관/` | 이전 판 (10/15 선생님 제출본 계획서, 계획서 초안) |
| `작업파일/` | 요구서·계획서를 다시 만들 때 쓰는 원본, 아두이노 스케치, 실험용 소리 파일 |

## 작업파일

- `작업파일/실험계획서/content.py` — 계획서 본문. 고친 뒤 `python build2.py`(pdf) → `node make.js`(docx)
- `작업파일/아두이노/turntable/turntable.ino` — 회전판 제어·배선 테스트 (명령: `?`, `w`, `e1/e0`, `m`, `h`, `g`, `z`)
- `작업파일/신호/make_signals.py` — 실험용 소리 파일 생성. 만들어 둔 파일은 `signals/` (채널 확인용 `00_채널확인.wav` 포함)
- `작업파일/요구서/` — 요구서 작업본 xlsx
